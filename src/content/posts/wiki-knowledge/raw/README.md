# Raw Sources（原始资料）

把你想纳入知识库的**原始资料**放进这个目录。本目录内容**不可变**——LLM 只读不改。

## 支持的类型
- 文章 / 博客 / 网页（可先存为 `.md` 或 `.txt`）
- 论文 / 报告 / PDF
- 书摘 / 读书笔记
- 会议纪要 / 文档
- 日记 / 随想 / 健康记录
- 图片（放 `assets/`，并在资料中注明）

## 怎么用
1. 把文件拖进 `raw/`（图片放 `raw/assets/`）。
2. 回到对话，告诉 LLM：「**摄入 raw/ 下的 <文件名>**」或「**摄入这份资料**」。
3. LLM 会读取资料 → 写摘要页 → 更新索引 → 更新相关实体/概念页 → 追加日志。
4. 之后你可以随时「**针对知识库提问**」，或让我做「**体检（lint）**」。

> 建议：一份资料一次摄入，质量更高。命名尽量带日期与主题，例如 `2026-07-25-注意力管理.md`。
